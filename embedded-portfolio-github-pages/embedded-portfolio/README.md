# คลังผลงาน Embedded — ชุดไฟล์สำหรับ GitHub Pages

เว็บรวมรายงานปฏิบัติการวิชา Embedded System ของ มงคล น้อยบาท (B6728960)
ทั้งหมด 9 ผลงาน พร้อมรูปประกอบ 60 รูป และไฟล์รายงาน PDF ครบทุกฉบับ

## ไฟล์ในชุดนี้

| ไฟล์ / โฟลเดอร์ | คืออะไร |
|---|---|
| `index.html` | ตัวหน้าเว็บ รวมข้อมูลผลงานทั้งหมดไว้ข้างใน |
| `media/` | รูปจากการทดลอง 60 รูป |
| `reports/` | ไฟล์รายงาน PDF ทั้ง 9 ฉบับ |
| `.nojekyll` | ไฟล์เปล่า บอก GitHub ไม่ต้องประมวลผลเว็บซ้ำ ห้ามลบ |

## วิธีขึ้น GitHub Pages

1. ล็อกอิน GitHub แล้วกด **New repository**
2. ตั้งชื่อ repository
   - ถ้าตั้งชื่อว่า `ชื่อผู้ใช้.github.io` เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/`
   - ถ้าตั้งชื่ออื่น เช่น `embedded` เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/embedded/`
3. เลือก **Public** (ถ้าเลือก Private จะเปิด Pages ฟรีไม่ได้) แล้วกด **Create repository**
4. ในหน้า repository กด **uploading an existing file** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้เข้าไป
   รอจนอัปโหลดครบทุกไฟล์ แล้วกด **Commit changes**
5. ไปที่ **Settings → Pages** ตั้ง Source เป็น **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอประมาณ 1-2 นาที แล้วเปิดลิงก์ตามข้อ 2

## เวลาต้องการอัปเดตผลงาน

ข้อมูลผลงานทั้งหมดเก็บอยู่ในบล็อก `<script id="app-state">` ภายใน `index.html`
เป็น JSON ที่แก้ไขด้วยโปรแกรมแก้ข้อความอะไรก็ได้ แต่ละผลงานมีโครงแบบนี้

```
"code"       รหัสงาน เช่น Wk02, Day0100
"date"       วันที่รูปแบบ 2026-07-09
"status"     done, wip หรือ draft
"title"      ชื่อผลงาน
"subtitle"   ชื่อรอง
"summary"    สรุปย่อหนึ่งย่อหน้า
"tags"       หมวดหมู่ เป็นรายการข้อความ
"items"      ภารกิจและการทดลอง เป็นรายการข้อความ
"tools"      อุปกรณ์และเครื่องมือ เป็นรายการข้อความ
"images"     ที่อยู่รูป เช่น media/wk02-01.jpg รูปแรกคือภาพปก
"reportUrl"  ที่อยู่ไฟล์ PDF เช่น reports/wk02-siemens-logo8.pdf
"links"      ลิงก์ภายนอก แต่ละอันมี label กับ url
"note"       หมายเหตุ
```

เพิ่มรูปใหม่ให้วางไฟล์ไว้ในโฟลเดอร์ `media/` แล้วเติมที่อยู่ไฟล์เข้าไปใน `images`
เพิ่มรายงานใหม่ให้วางไฟล์ PDF ไว้ใน `reports/` แล้วใส่ที่อยู่ใน `reportUrl`
ระวังเรื่องเครื่องหมายจุลภาคและวงเล็บปีกกาของ JSON ให้ครบ ไม่งั้นหน้าเว็บจะว่างเปล่า

ถ้าไม่สะดวกแก้เอง ส่งไฟล์ .docx ฉบับใหม่มาให้ Claude สร้างชุดไฟล์ใหม่ให้ได้เหมือนเดิม

## หมายเหตุ

- ทุกอย่างในเว็บทำงานได้โดยไม่ต้องต่ออินเทอร์เน็ตกับบริการภายนอก ยกเว้นฟอนต์ IBM Plex ที่โหลดจาก Google Fonts ถ้าโหลดไม่ได้จะใช้ฟอนต์ของเครื่องแทน หน้าเว็บยังอ่านได้ปกติ
- เว็บรองรับทั้งโหมดสว่างและโหมดมืดตามการตั้งค่าของเครื่องผู้อ่าน และใช้งานบนมือถือได้
- ไฟล์รวมกันประมาณ 20 MB อยู่ในโควต้าของ GitHub Pages สบายๆ
